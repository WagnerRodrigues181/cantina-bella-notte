# Cantina Bella Notte

SPA de restaurante, feita em HTML5 + CSS3 + JavaScript vanilla, sem frameworks.

## Stack

- HTML5 semântico
- CSS3 puro (custom properties, Grid, Flexbox)
- JavaScript ES6+ vanilla
- Google Fonts (Playfair Display + Lato)
- Lucide Icons (CDN)

## Estrutura

```
cantina-bella-notte/
├── index.html
├── css/       (reset, variables, base, layout, components, sections, animations, responsive)
├── js/        (main, menu, animations)
└── assets/    (images, icons)
```
